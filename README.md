# 👻 BOOCLI

A spooky interactive ghost companion for your terminal!

## 📦 What's in This Repo?

This repository contains **two** ghost-themed apps:

1. **BOOCLI** (Terminal App) - Spooky ghost companion for your command line
2. **GhostClipboard** (macOS & iOS Apps) - Clipboard manager with cloud sync

Navigate to each folder for specific documentation:
- Terminal app: This README (root directory)
- Clipboard apps: [`GhostClipboard/README.md`](./GhostClipboard/README.md)

## What is this?

Ever felt lonely while coding late at night? Fear not! BOOCLI brings you ghostly companions, spooky fortunes, and tales of tech horror to keep you company in the terminal.

## Features

- 👻 **Multiple Ghost Personalities**: Meet different ghosts with unique ASCII art
- 🔮 **Fortune Telling**: Get spooky predictions about your code's future
- 📖 **Ghost Stories**: Listen to tales of infinite loops, missing semicolons, and haunted repositories
- 😱 **Terminal Haunting**: Get spooked by random ghost appearances
- 🎨 **Colorful Animations**: Beautiful gradients, animations, and visual effects
- 🎲 **Interactive Mode**: Summon a ghost and choose your own adventure
- ⚰️ **Tech Graveyard**: Pay respects to deprecated technologies

## Installation

```bash
cd boocli
npm install
```

### Run Locally

```bash
npm start
```

### Install Globally (Optional)

```bash
npm install -g .
```

Then you can use `boocli` from anywhere!

## Usage

### Interactive Mode (Default)

Simply run with no arguments to summon an interactive ghost:

```bash
boocli
```

or

```bash
npm start
```

### Commands

#### 👻 Get Haunted

```bash
boocli haunt
```

A random ghost will appear and spook you with a haunting message!

#### 🔮 Fortune Telling

```bash
boocli fortune
```

The Ghost King will peer into your future and reveal what the spirits see...

#### 📖 Ghost Story

```bash
boocli story
```

Listen to a terrifying tale of tech horror. Perfect for campfires or late-night coding sessions.

#### 🎲 Summon Interactive Ghost

```bash
boocli summon
```

Summon a friendly ghost and choose what you want it to do. The ghost will stick around until you dismiss it!

#### ⚰️ Visit the Graveyard

```bash
boocli graveyard
```

Pay your respects to Netscape Navigator, Internet Explorer, Flash, and other fallen heroes of the web.

## Examples

```bash
# Get your fortune
boocli fortune

# Hear a spooky story
boocli story

# Just want to be spooked?
boocli haunt

# Interactive fun
boocli summon
```
