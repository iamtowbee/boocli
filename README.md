# 👻 BOOCLI

A spooky interactive ghost companion for your terminal!

## 📦 What's in This Repo?

1. **BOOCLI** - Terminal ghost companion with fortunes, stories, and ASCII ghosts
2. **GhostClipboard** - macOS/iOS clipboard manager with cloud sync ([docs](./GhostClipboard/README.md))

## Installation

```bash
npm install
npm start
# Or install globally: npm install -g .
```

## Usage

```bash
boocli              # Interactive mode (default)
boocli haunt        # Random ghost appearance
boocli fortune      # Get your fortune
boocli story        # Hear a spooky story
boocli graveyard    # Visit deprecated tech graveyard
```

## Features

- 👻 Multiple ghost personalities with ASCII art
- 🔮 Fortune telling for your code's future
- 📖 Ghost stories of tech horror
- 🎨 Colorful animations and gradients
- 🎲 Interactive mode
- ⚰️ Tech graveyard tribute

## Tech Stack

Node.js • chalk • commander • inquirer • ora • figlet • gradient-string
