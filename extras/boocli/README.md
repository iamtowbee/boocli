# 👻 BOOCLI - Original Terminal Ghost Companion

The original BOOCLI - a fun Node.js terminal companion with ghosts, fortunes, and stories!

## Quick Start

```bash
npm install
npm start
```

## Usage

```bash
boocli              # Interactive mode
boocli haunt        # Get haunted
boocli fortune      # Get your fortune
boocli story        # Hear a spooky story
boocli graveyard    # Visit the tech graveyard
```

## Features

- 👻 Multiple ghost ASCII art personalities
- 🔮 Fortune telling
- 📖 Spooky tech stories
- 🎨 Colorful animations
- ⚰️ Tech graveyard tribute

## Note

This is the original standalone version. The main GhostClipboard CLI (`../CLI/`) now includes these fun features as extras alongside clipboard management!
